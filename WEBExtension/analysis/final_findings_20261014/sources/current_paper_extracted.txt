Signal over Chatter: Decomposing Routing, Rationing, and
Stopping in Multi-Agent Web Information Seeking and Reasoning
Anonymous Author(s)
Abstract
Multi-agent large language model (LLM) systems coordinate across
Web information-seeking and collaborative reasoning pipelines by
exchanging natural-language traces, but broadcasting full reason-
ing and retrieved evidence introduces substantial token overhead.
Reducing this cost is challenging because communication depends
simultaneously on which agents communicate (routing), how much
contenteachchannelcarries (rationing),andhowmanyroundstheex-
change continues (stopping). Because LLM messages vary in length,
pruning a directed edge also alters transmitted token volume, leav-
ing standard topology comparisons volume-confounded.
We formalize this attribution problem and introduce SparseC-
omm, a Proximal Policy Optimization (PPO) communication con-
troller that serves as a controllable experimental instrument across
closed-book reasoning (GSM8K, AQuA-RAT, HotpotQA) and open-
book Web candidate retrieval (HotpotQA fullwiki with BM25).
Across primary benchmarks, SparseComm reduces inter-agent
transmitted tokens by 50.4%–90.2% while remaining statistically
non-inferior to fully connected Multi-Agent Debate and improving
over zero-communication ensembles by 3.9–8.5 percentage points.
A factorial diagnostic reveals that switching routing alone contracts
realized token volume by 3.4×, showing that unconstrained topol-
ogy comparisons capture a volume-confounded total effect rather
thanapurestructuraleffect.Underanexhaustivebudget-controlled
enumeration of directed two-edge topologies on GSM8K, SparseC-
omm consistently outperforms static graph supports while consum-
ing less than 32% of the nominal token budget. Finally, component-
isolation and Web retrieval ablations disentangle static topology
alignment from consensus stopping and prefix rationing, showing
that each mechanism independently reduces token overhead while
preserving reasoning fidelity. Code, checkpoints, and raw traces
are available at https://anonymous.4open.science/r/sparsecomm-
WWW2027.

1 Introduction
Multi-agent language-model (LLM) systems coordinate by exchang-
ing text across Web APIs, retrieval pipelines, and collaborative
reasoning workflows. Multi-agent debate and role-specialized de-
liberation improve mathematical and factual reasoning [7, 17, 19],
repository-levelsoftwareengineering[11,24],andopen-endedWeb
task automation [9, 15, 34, 38]. Across the Web ecosystem, however,
this coordination incurs substantial communication overhead. In a
fully connected broadcast protocol, agents repeatedly exchange rea-
soning traces and retrieved evidence with all peers, causing token
traffic to scale with both the number of directed channels 𝑁(𝑁 −1)
and the number of deliberation rounds𝑇. Because natural-language
messages have variable length, the realized cost of an exchange
depends not only on which agents communicate, but also on how
much content each channel carries and when deliberation terminates.
We distinguish these three decisions as routing, rationing, and
stopping. Routing determines which directed sender–receiver chan-
nels participate in a round; rationing determines how much content
is transmitted on an active channel; and stopping determines the
executeddeliberationdepth.Recentcommunication-efficientframe-
works prune agents or messages [32, 36], while topology-learning
systems optimize the communication graph itself [16, 27, 37, 38].
Although these methods reduce pipeline-level token usage substan-
tially, their reported gains are properties of the joint communica-
tion policy as a whole. Specifically, unless realized communication
volume is explicitly controlled, changing a communication graph
simultaneously alters the amount of text transmitted: removing a
directed channel removes a variable-length message whose real-
ized size is generated by the LLM. A comparison that alters graph
support without controlling transmitted volume therefore does not
isolate a topology-only effect.
This paper studies that causal attribution problem across both
closed-book multi-agent reasoning and open-book Web informa-
tion seeking. We use SparseComm, a reinforcement-learning com-
munication controller trained with Proximal Policy Optimization
(PPO) [26], as a controllable experimental instrument that parame-
terizes continuous edge intensities, sentence-level and prefix-based
message rationing, and consensus-driven adaptive stopping within
a common three-agent deliberation pipeline. Across GSM8K [4],
AQuA-RAT[18],andclosed-bookHotpotQA[35](ProtocolsP1–P5),
as well as candidate-based open-book Web retrieval on HotpotQA
fullwiki (Protocols W1–W4), SparseComm substantially reduces
inter-agent transmitted volume while preserving task performance
close to fully connected debate. The purpose of this result is not
to claim an unconstrained state-of-the-art leaderboard ranking,
but to establish a rigorous experimental framework in which the
mechanisms driving multi-agent communication efficiency can be
decomposed and audited.

2 Related Work
Collective reasoning by multi-agent debate. Multi-agent debate
improves factuality and mathematical reasoning by allowing LLM
instances to critique intermediate solutions across rounds [2, 7,
17, 19]. Similar collaborative message-passing architectures power
multi-agent Web assistants and software engineering frameworks
such as AutoGen [34], CAMEL [15], MetaGPT [11], ChatDev [24],
AgentVerse [3], and AgentScope [9]. Because these systems fix a
dense broadcast or static role-chain topology in advance, commu-
nication volume is a byproduct of the architecture rather than a
controlled variable; they serve as our high-communication refer-
ence point (MAD).
Communication-efficient pruning and graph learning. A second
line of work treats inter-agent communication as a budget to spend
selectively via edge pruning, message compression, or dynamic
agentelimination,includingAgentPrune[36]andAgentDropout[32],
alongside prompt compression methods such as LLMLingua [13]
and LLMLingua-2 [21]. A third line optimizes the communica-
tion graph itself using graph neural networks, continuous relax-
ation, or autoregressive generation, including GPTSwarm [38], G-
Designer [37], ARG-Designer [16], and propagation analyses [27],
extending classic multi-agent reinforcement learning (MARL) liter-
ature on targeted continuous or gated communication [5, 8, 14, 28,
29].
In classic MARL, however, inter-agent messages are fixed-width
continuous vectors, so gating an edge alters what is transmitted
without altering vector dimensionality, making topology compar-
isons volume-controlled by construction. LLM agents break that in-
variance: messages are variable-length token sequences, so editing
an edge changes transmitted token volume by a model-dependent
amount. Pruning an agent or edge removes its channels and its
variable-length payloads simultaneously; by Proposition 2, even
a factorial design does not separate routing from volume unless
transmitted mass is explicitly constrained. Table 7 in Appendix A
positions SparseComm relative to these systems by primary mech-
anism.
Multi-hopWebinformationaccess. HotpotQA[35]evaluatesmulti-

benchmark origin does not make execution regimes equivalent, we
explicitly distinguish closed-book multi-agent deliberation (where
agents rely on parametric knowledge without passages; Protocols
P1/P1b) from open-book candidate retrieval (where retrieval, verifi-

via local BM25 and are scored with the official HotpotQA evalua-

6.2 Why the 2 × 2 Factorial Estimates a Total
Effect (P2 & P2b)
In Protocol P2, Factor𝑇 ∈ {0,1} switches a fixed ring support to
the learned continuous intensity policy, while Factor 𝐶 ∈ {0,1}
switches full unfiltered messages to semantic sentence filtering
(Arm 00: fixed/full; Arm 01: learned/full; Arm 10: fixed/filtered;
Arm 11: full SparseComm). We fit the saturated linear probability
model 𝑌𝑞 = 𝛽0 + 𝛽𝐶𝐶𝑞 + 𝛽𝑇𝑇𝑞 + 𝛽𝐶𝑇𝐶𝑞𝑇𝑞 + 𝜖𝑞 with CR1 standard
errors clustered by question [1] across separate controllers trained
on 𝑛train ∈ {100,200,300,400} examples (Figure 2, Table 10). After
Holm correction across the twelve non-intercept tests [10], no main
effect or interaction is statistically distinguishable from zero (all
𝑝Holm ≥ 0.416; widest 95% CI half-width ≈ 16 points, yielding 80%
power only for effects of 11.5–16.5 points).
Theper-cellvolumelogsinProtocolP2b(Table9andFigure1(a)),
however, expose the exact identification failure predicted by Propo-
sition 2. Holding the message rule fixed at full transmission (𝑐 = 0)
and switching only routing (𝑇 : 0 → 1), realized volume drops
from 366 tokens (Arm 00) to 109 tokens (Arm 01), a contraction fac-
tor of 3.4× (removing 257 tokens/question). Holding routing fixed
(𝑡 = 0) and switching only the message filter (𝐶 : 0 → 1), volume
moves from 366 to 344 tokens, a factor of only 1.06×. Furthermore,
the two interventions interact multiplicatively on volume: along
the second row/column, routing contracts filtered volume from
344 to 59 tokens (5.8×), while filtering contracts learned-routing
volume from 109 to 59 tokens (1.85×). Thus, toggling the routing
switch in a variable-length LLM system acts primarily as a massive
volume intervention, rendering any unconstrained factorial accu-
racy contrast a sum of direct routing and indirect volume effects
(𝛽𝑇 = Δroute + Δvolume).

8 Discussion and Implications
In LLM multi-agent systems, a graph edit is also a token edit.
Our central methodological finding is that communication routing
and message volume are structurally coupled whenever agents ex-
change variable-length natural language. Proposition 2 proves that
unconstrained topology contrasts include an indirect volume effect
Δvolume, and Protocol P2b measures its magnitude at 3.4× (257 to-
kens/question). Prior communication-efficient frameworks [32, 36]
and graph learners [16, 37, 38] report substantial pipeline-level
savings, which remain practically valuable; however, attributing
those gains specifically to graph structure requires controlling real-
ized volume via shared caps (P4), matched-depth isolation (P5), or
per-question quota matching (W4).
Adaptive control vs. static graph wiring. Exhaustive enumeration
of all 15 directed two-edge supports in P4 (Table 11) demonstrates
that static sparse wirings cluster within a narrow band (75.56%–
76.22% across motif classes at ¯ 𝑉 = 50), whereas the full learned PPO
policy reaches 91.87%–92.00% across 5 seeds. When P5 matches the
static out-star support 𝑆1 = (0 → 1,0 → 2), per-edge token sched-
ule, and round depth, controller-induced top-2 routing coincides
with 𝑆1 on 100% of rounds (91.0% accuracy), while adaptive stop-
ping delivers the 69.6% token reduction (46 → 14 tokens) and +2.0
point accuracy lift (93.0%). Likewise, in open-book Web QA (W3),
consensus stopping delivers 38.6–40.4% communication reductions
while improving or preserving 𝐹1 across both retrieval regimes. To-
gether, these results indicate that efficient multi-agent coordination
is primarily governed by adaptive control of communication
depth and budget allocation on a coherent hub/chain backbone,
rather than complex per-question graph rewiring.
Task-dependent operating regimes: Reasoning vs. Web QA.. Com-
paring closed-book math reasoning (GSM8K, AQuA-RAT), closed-
book multi-hop QA (HotpotQA P1), and open-book Web candidate
retrieval (HotpotQA W1–W4) reveals a clear mechanism bound-
ary. When agents generate complementary deductive derivations
(GSM8KandAQuA-RAT),sparsedirectedcommunicationanchored
at the Analytical solver (0 → 1,0 → 2) yields large gains over No-
Comm (+8.53 and +3.94 pp) at a fraction of broadcast cost. When

10 Conclusion
Routing, rationing, and stopping are distinct control decisions in
multi-agent language models because topology edits in variable-
length text communication simultaneously alter transmitted token
volume.Throughformalmediationdecompositions(Propositions1–

by 50–90% while maintaining non-inferior accuracy relative to full
debate,andthatadaptivestoppingandstructuredbudgetrationing—
ratherthanunconstrainedgraphswitching—aretheprimarydrivers
of verified efficiency gains.
