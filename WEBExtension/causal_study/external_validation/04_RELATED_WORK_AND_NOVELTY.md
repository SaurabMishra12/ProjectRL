# Related work and novelty gate

**No new mechanism or general evaluation theory has been independently established.** A bounded primary-source comparison finds close precedents for proposal/readout separation, collaboration-assisted abstention, context sufficiency and aggregator/debate ablations. It does not prove that every possible intersection has already been published.

- **Debate or Vote** (NeurIPS 2025): Initial vote versus communication; theoretical update assumptions; empirical debate controls. Generic debate-versus-vote question already studied. [Primary source](https://arxiv.org/html/2508.17536v2).

- **When Debate Helps** (2026 preprint): Proposal supply/readout separation; fixed-proposal verification probes. Readout dependence and minority recovery are not new. [Primary source](https://arxiv.org/html/2610.04686v1).

- **Beyond Majority Voting** (ICML 2026): Reliability/dependence-aware aggregation beyond vote counts. Ordinary aggregation improvement is insufficient novelty. [Primary source](https://arxiv.org/html/2510.01499v2).

- **Don't Hallucinate, Abstain** (ACL 2024): Cooperative/competitive multi-LLM knowledge-gap abstention; retrieval/multihop analyses. Multi-agent abstention is established. [Primary source](https://aclanthology.org/2024.acl-long.786/).

- **Sufficient Context** (ICLR 2025): Context sufficiency and selective-generation trade-offs. Reference presence and missing annotations cannot define sufficiency. [Primary source](https://arxiv.org/html/2411.06037v3).

- **MADAM-RAG / RAMDocs** (COLM 2025): Conflicting retrieved evidence; aggregator and debate-round ablations. Generic aggregator-by-debate Web/RAG claim overlaps. [Primary source](https://arxiv.org/html/2504.13079v2).

- **EARS** (2026 preprint): Explanatory sub-agent abstention transmitted to coordinator. Abstention as communication signal already studied. [Primary source](https://arxiv.org/html/2606.18668v1).

- **MuSiQue-Full** (TACL 2022): Paired same-question answerability under source removal; grouped sufficiency evaluation. Using existing contrasts is not a new benchmark. [Primary source](https://aclanthology.org/2022.tacl-1.31/).

- **Knowing When Not to Answer** (2026 preprint): Multimodal multi-agent abstention and accuracy/abstention trade-offs. Broad multi-agent abstention trade-off is not new. [Primary source](https://arxiv.org/html/2604.14799v1).

- **Free-MAD** (FindingsACL 2026): Consensus-free trajectory-based decision; parsed-None filtering in inspected preprint. Do not claim None filtering or alternative debate readout is novel. [Primary source](https://aclanthology.org/2026.findings-acl.1600/).

These sources were checked through original papers or official proceedings; discovery-only search snippets were not used as findings. Preprints remain labeled preprints. The only residual candidate is narrower: **does a benchmark-compatible abstention contract materially alter the measured peer-versus-private-revision effect, and does that alteration differ between source-sufficient and source-insufficient contexts?** It would need independent data, correct source-bound answer obligations and a consequence that persists against competent prespecified aggregation. Combining familiar words in a title is not a contribution.

A credible **A, findings paper**, requires a consequential independently observed interaction or a well-supported boundary/heterogeneity result. The zero aware interaction in the external numeric contract is informative about compatibility, but does not supply the missing Web evidence. **B, protocol/benchmark**, requires validated reusable labels, ambiguous-case adjudication, independent implementations and evidence that existing protocols miss something important. This phase provides preparation, not that validation. **C, limited implementation audit**, is supported now and does not justify a WWW main-track claim by itself.

The Web connection is static Wikipedia-derived evidence and RAG-style source support. Neither GSM8K arithmetic nor simply renaming the readout creates a Web contribution. A stronger claim would require demonstrable consequences of evidence availability/provenance for source-bound answer obligations. The present material provides no live-Web result.
