1. Persona Retention vs. Persona EradicationThe Python code initializes the agents with distinct system prompts: Agent 0 is "analytical", Agent 1 is "step_by_step", and Agent 2 is "creative". The reasoning logs expose how each architecture handles these unique identities.  The "Creative" Agent Signature: In isolated reasoning (No Comm) and the weighted model (Our Model), Agent 2 consistently interprets its "creative" prompt by generating multiple pathways to the answer. It frequently uses formatting like "Approach 1" and "Approach 2" and explicitly judges the elegance of the math. For instance, in Example 10, Agent 2 states, "Both methods give the same result; the algebraic shortcut is the more elegant".  The MAD Homogenization: In the Multi-Agent Debate (MAD) architecture, this diversity is completely eradicated. Because MAD uses a uniform weight of 1.0, agents are forced to ingest the full, uncompressed context of their peers. By the final round, the "creative" Agent 2 abandons its multiple-approach formatting and outputs the exact same text block as the "analytical" Agent 0 (e.g., Example 2, where all three MAD agents output the exact same four steps verbatim).  The Weighted Pattern: "Our Model" successfully preserves the individual agent personas. Agent 2 retains its "Approach 1 / Approach 2" structure while still absorbing the correct mathematical logic from the fragmented messages sent by Agent 0 and Agent 1.  2. The Truncation Vulnerability (Context Bloat)The dataset exposes a critical vulnerability related to context window limits and token generation.Mid-Sentence Collapse: Models that do not compress their communication suffer from severe text truncation. In Example 3, the isolated No Comm model's reasoning cuts off mid-equation: "Money obtained from selling $x$ sets = $(". In Example 14, the No Comm reasoning abruptly ends at the number "4".  The Cause: When agents process uncompressed messages, the prompt becomes bloated. The model exhausts its token budget before completing its logic chain.The Compression Solution: The communication excerpts for "Our Model" show that the system transmits heavily fragmented, byte-sized payloads (e.g., Agent 1: 2.. 3.. 4.. Calculate the number of lego sets remaining.). By passing only the mathematical anchors, the agents conserve their token budget, allowing them to finish their reasoning and output a complete answer.  3. Syntax Segregation: Math vs. ProseA hidden pattern emerges in how the weighted model absorbs peer feedback compared to the debate baseline.String Duplication in MAD: The MAD baseline agents copy their peers' text word-for-word. In Example 1, the MAD final reasoning traces across all agents are identical clones, matching character for character.  Semantic Abstraction in Our Model: "Our Model" treats peer communication as data rather than a script. The communication trace in Example 9 shows that the model routes raw equations (e.g., \text{Cognac bottles}=2 \times 10 = 20). The receiving agent parses this math and rewrites the surrounding prose in its own distinct voice. The model segregates the mathematical logic from the linguistic syntax.  4. The Confidence Formatting ShiftThe way the agents format their self-reported confidence scores reveals a shift in how they calculate uncertainty.Integer Defaulting: The MAD and No Comm models universally output hard integers for their confidence, almost always printing Confidence: 10 or Confidence: 9. They treat the prompt instruction as an absolute binary scale.  Decimal Probabilities: "Our Model" shifts its formatting entirely, generating fine-grained decimals like Confidence: 0.99 and Confidence: 1.0. This hidden formatting shift suggests that exposure to compressed, fractional peer communication prompts the Large Language Model to adopt a more probabilistic, statistical frame of reasoning rather than a definitive one.
